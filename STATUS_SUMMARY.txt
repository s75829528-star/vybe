CONFIGURATION REQUIRED FOR LIVE BACKEND USE
- Client .env variables:
  EXPO_PUBLIC_SUPABASE_URL
  EXPO_PUBLIC_SUPABASE_ANON_KEY
  EXPO_PUBLIC_CLOUDINARY_CLOUD_NAME (optional, displayed in app information)
- Supabase Edge Function secrets:
  CLOUDINARY_CLOUD_NAME
  CLOUDINARY_API_KEY
  CLOUDINARY_API_SECRET
- Supabase provides SUPABASE_URL, SUPABASE_ANON_KEY, and
  SUPABASE_SERVICE_ROLE_KEY to Edge Functions. Never place the service-role key
  or Cloudinary API secret in the client .env or Android bundle.
- Create/sign in to an account, then grant admin access from the trusted SQL
  editor with:
  update public.profiles set role='admin' where id='<user-uuid>';
